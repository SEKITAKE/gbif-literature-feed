# gbif-literature-feed
This repository generates RSS to track new papers that use GBIF data.

## Subscribe
You can subscribe to the feed using the following URL.
https://sekitake.github.io/gbif-literature-feed/feed.xml
The feed is updated once a day at 20:00 UTC.
